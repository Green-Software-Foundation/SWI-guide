# Open Methodological Questions

This page tracks methodological questions the SSWG has raised but not yet
resolved. It is a **living tracker**, not a one-time snapshot — it should
be updated as each item is resolved, and it is expected to shrink over
time, not grow. Per this guidance's own constraints, none of these
questions is resolved on any other page: where a page touches one of these
topics, it presents the live debate and links back here rather than
picking an answer.

## Why these live here, and not in the specification

The specification does not take a position on any of the six questions
above, and this guidance does not either — presenting an unresolved
question as settled, even implicitly, would misrepresent where the SSWG
actually stands. Each linked page above explains the question in context
and flags it as open at the point where a reader would otherwise expect a
definitive answer.

## Updating this page

When the SSWG resolves one of these questions, update its **Status**
column here, and update the corresponding page(s) to reflect the resolved
position rather than presenting it as still open. Do not remove a resolved
row silently — note the resolution and the date, so the history of how the
methodology settled remains visible.
