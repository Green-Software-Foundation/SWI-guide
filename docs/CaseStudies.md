# Case Study Submissions

This page lists worked, real-world applications of the SWI methodology
submitted by the community. Where the [Worked Examples](./QuickGuide.md)
page uses a small, illustrative scenario to demonstrate mechanics, case
studies here go further: real software systems, real data sources
(disclosed), and the boundary and allocation decisions that a real
assessment actually required.

## Submitting a case study

Open an issue using the `case-study-template` issue form in this
repository. It walks through the same structure the specification uses for
the assessment itself — Overview, Architecture, sites of water action
(direct operational, indirect operational, embodied), and the
Bound → Scale → Define → Quantify → Report procedure — so a submission
maps directly onto the concepts explained elsewhere in this guidance.
Submissions are reviewed per the
[Review Process](./ReviewProcess/Data.md) before being added here and to
`use-case-submissions/`.
